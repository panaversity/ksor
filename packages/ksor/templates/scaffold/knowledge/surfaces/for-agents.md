Agents reach the record through MCP — search and retrieval that answer with
citations, and abstain when the corpus does not cover the question. Beside it
the build publishes the same knowledge as plain files an agent can fetch
directly.

Abstention is a feature. "Not in this record" is a correct answer, and never a
licence to fall back on what a model happens to remember.
