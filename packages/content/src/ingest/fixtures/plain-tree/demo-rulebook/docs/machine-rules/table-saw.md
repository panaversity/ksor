# Rule 20: The Table Saw

The table saw is the workshop's most dangerous machine, and it is treated that way. The blade
guard and riving knife stay on for every through-cut; removing them requires a steward's
sign-off recorded in the log book. Push sticks are mandatory for any rip narrower than six
inches. Never reach over a spinning blade — walk around the table. The saw's SawStop cartridge
is tested on the first Monday of each month; if the brake has fired, the machine stays red-tagged
until a steward replaces the cartridge AND the blade together.
