# Rule 30: Injuries

For any injury beyond a minor scrape: stop the machine with the red paddle, shout for help, and
call emergency services before calling any workshop number. The first-aid station is on the
north wall next to the eyewash; the AED is by the front door. Every injury, however small, gets
an incident report the same day — the report protects the next member, not the paperwork. Blood
on a machine means the machine is red-tagged until a steward has cleaned and inspected it.
